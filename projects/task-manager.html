Student Task Manager

A REST API where students sign up, log in and manage their own tasks, built to practice backend basics and a clean Git workflow.

  • Node.js
  • Express
  • SQLite
  • JWT
  • Automated tests

What it does

  • Students register and log in. Passwords are hashed and never returned.
  • Logged-in students create, update, complete and delete only their own tasks.
  • Tasks can be searched and filtered by status and priority.
  • Bad input returns a clear 400 error. Unexpected errors return a safe 500 message with no internal details.

How I built it

  • Node.js and Express for the API, SQLite for storage, JWT for authentication.
  • Separate feature, bugfix and hotfix branches on GitHub, with small commits.
  • 56 automated tests cover authentication, validation, filters and error handling. All of them pass.
